# 验证命令与证据边界

根据本次改变的行为选择最小充分验证；同一改动已覆盖的检查不重复运行。涉及数据丢失、上传契约、生成来源或跨进程持久化时，应覆盖对应不变量。禁止新增 UI 单元测试；既有 UI/端到端回归可按需运行。


- 修改 Swift 源码时可运行 `make check`，执行严格 `swift-format` 检查与通用 iOS 设备静态分析。
- 修改用户主链路、数据模型或图像处理时可运行 `make test`；不能用单次编译代替 UI 与像素证据。
- 修改默认 AI 贴纸主链路、系统确认页、透明代理、能力不可用恢复或人物与穿搭复核时选择 `make ai-sticker-regression`；它同时运行 Node 代理契约与 iOS 测试，锁定用户先确认 AI 底图、第二段只上传该底图、服务端按 GPT Image 透明 PNG 契约请求、双端拒绝假透明、客户端程序化白边、无 Vision/原图直抠兜底、两段 provider 元数据、最终贴纸复核、保存导出及 Debug UI 产品链路。该命令不替代真实 Apple/OpenAI 请求、人物/穿搭保真、弱网、公开代理安全或真实 iPhone。
- 修改 Apple 图片生成适配、SDK 条件或 provider 抽象时选择 `make legacy-provider-isolation`；它执行禁用旧适配器的干净 Release 构建，确认受支持的系统 Image Playground 框架仍在、旧 `ImageCreator` 未解析符号已经移除，并验证旧程序化生成器诚实报告不可用。当前门禁模拟未来 SDK 不启用旧条件，不替代实际 Xcode 27 构建或真实系统页运行。
- 修改模型、提示、分割或贴纸/收藏卡后处理时选择 `make sample-regression`；它同时校验历史直抠样片的仓库哈希、macOS Vision 字节级重生成与成品结构，以及首页 AI 底图/绿幕/透明贴纸哈希、绿幕到真实 Alpha 的字节级重建和人工结论。它不证明默认 GPT Image 透明编辑质量或人物/穿搭保真。新默认链路同时检查是否需要运行 `make ai-sticker-regression`，并在具备服务端密钥时用授权样片做真实 provider 目检。C 级 sample-04 不得删除。
- 修改布局、文案、颜色、动效、无障碍语义或生命周期状态时选择 `make accessibility-regression`；脚本会临时启用最大辅助字号与增强对比度，覆盖 AI 贴纸复核在两图纵向对照、多选、保存与历史回看中的滚动可达性，并在退出时恢复模拟器设置。
- 修改相机入口、权限状态、权限文案或设置恢复路径时选择 `make permission-regression`；拒绝态必须提供系统设置入口，系统限制态不得承诺用户能在 App 设置中解除。
- 修改透明贴纸存入相册、PhotoKit 权限、PNG 资源写入或失败后的重试/分享动作时选择 `make photo-save-regression`；成功夹具只证明页面状态，PNG 单元测试只证明交给 PhotoKit 边界的字节，二者都不证明系统照片中已经得到透明 PNG。
- 修改 SwiftData 容器、数据库或媒体位置、收藏事务、启动恢复或本地记录生命周期时选择 `make persistence-regression`；测试必须真实终止并重新启动 App，且不得用同一进程内重新打开页面代替。
- 修改衣橱视觉签名、商品图或 OOTD 像素分析、候选权重/文案、签名回填或导出字段时选择 `make wardrobe-visual-regression`；它覆盖背景归一化、图案干扰项、弱证据降级、旧记录回填、当前导出和真实一键确认 UI。
- 修改生成计时、截止任务、处理事件、预算、重试、超时降级、外部请求、设置页性能摘要或性能导出字段时选择 `make performance-regression`；它覆盖成功、失败、取消、超时、迟到结果隔离、基础贴纸持久化、超预算、结构化导出和可见诊断。
- 修改月度 Lookbook 的数据选择、排版、文案、来源说明或分享入口时选择 `make lookbook-regression`；它覆盖空月份隐藏、收藏后出现、固定社交尺寸、不透明输出、最近 6 条与系统分享入口。
- 修改花影海报或风格花园的配方、系统样式、供应适配、能力门控、排版、像素来源、取消/超时、收藏事务、历史回看、事件或导出字段时选择 `make creative-regression`；它覆盖程序排版与三种 AI 配方契约、动态来源、固定尺寸、不透明输出、单入口三选项、系统能力隐藏/可用、取消、超时、原图对照、跨进程回看、系统分享、v9 导出与完整清理。系统成功路径使用仅 Debug 的夹具，不替代真实 Apple 生成与真机验证。
- 修改贴纸试搭的准入、人体姿态、抠图、白边、位置、界面、取消、来源、收藏、分享、历史、事件或导出字段时选择 `make tryon-regression`；它覆盖干净商品图门槛、真实 Vision 或明确运行时边界、脸部像素不变、上身变化、纯白描边、0 外部请求、取消、原图对照、系统分享和冷启动历史。Debug 固定姿态不替代真机 Vision、真实服装细节或泛化证据。
- 修改数字手办收藏卡的渲染、来源说明、结果或历史入口、分享流程时选择 `make figurine-regression`；它覆盖固定尺寸、不透明输出、原贴纸像素保留、空输入、结果页与已收藏历史入口，以及系统分享面板。
- 修改数字展柜的数据选择、排序、展位、关系摘要、花历入口或历史跳转时选择 `make cabinet-regression`；它覆盖空集合、稳定排序、显式衣橱关系、待确认与已移除状态、自动入口、真实 OOTD 回链和删除后的动态空态。
- 修改四季花历的数据选择、月份边界、跨年冬季、季节卡、花历入口、历史跳转或减压文案时选择 `make seasonal-regression`；它覆盖四季边界、跨年归档、稳定排序、自动入口、真实 OOTD 回链和删除后的动态空态。
- 修改“再次盛开”的目录、排序、名称降级、入口、来源回链、分享渲染或动态空态时选择 `make rebloom-regression`；它覆盖显式确认门槛、从未共同穿过、最久未穿排序、30 天理由、原图像素保留、固定分享尺寸、系统分享、真实 OOTD 回链和删除后即时失效。
- 修改“再次盛开”提醒的权限、调度、取消、替换、路由、失效清理、隐私文案或事件时选择 `make rebloom-reminder-regression`；它覆盖不主动索权、权限拒绝、一次性 7 天触发、单提醒替换、取消、私密通知内容、App 侧回链、删除后失效和清空数据时移除通知。
- 当前 iOS 26.5 模拟器的 Vision 推理上下文不可用，人体姿态请求也会报告主计算阶段没有可用设备。不得用假蒙版或固定姿态伪装生产成功；先阅读 [2026-08-29 iOS 本地 Demo 验证记录](../verification/2026-08-29-ios-local-demo.md)与 [贴纸试搭验证记录](../verification/2026-08-30-sticker-try-on.md)，并在可用真机上补做实时分割和人体姿态回归。
