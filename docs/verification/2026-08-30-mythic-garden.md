# 2026-08-30 永生花园系统创作验证

> 结论：Adonis 已完成第一个可选 AI 创作纵向切片“永生花园”。在 Apple 系统图片生成能力可用的设备上，用户可从现有贴纸结果一次点击开始固定插画创作，处理中可停止，90 秒未完成会退出等待；完成后可与原始照片对照、收藏、分享，并在 App 终止重启后从原 OOTD 回看。画面明确标为 AI 生成，人物、衣物、背景和画风都可能改变。
>
> 当前证据只证明系统 API 适配、产品交互、来源标识、生命周期和数据链路。iOS 模拟器中的成功图片来自仅 Debug 的确定性夹具，不是 Apple `ImageCreator` 的真实输出，因此不能证明真实风格质量、身份或衣物保真、真实时延、真实网络行为、费用或用户分享意愿。

## 1. 用户看到什么

- 没有 Prompt、Skill、模型、工作流、风格参数或供应商选择。
- 只有当 `ImagePlaygroundViewController.isAvailable` 为真时，结果页才出现“永生花园”；能力不可用时整个入口隐藏，不留下不可点击说明或升级压力。
- 入口在点击前直接说明“会重新绘制人物、衣服和背景”，不把它包装成保真滤镜或试穿。
- 处理中显示“系统会重新绘制整张画面，最多等待 90 秒”，并提供至少 44pt 的“停止这次创作”。
- 成品在“永生花园 / 原始照片”之间切换；来源卡固定显示“AI 生成”，边界卡固定显示“人物和衣服都可能改变”。
- 分享图片页脚固定为“AI 生成画面 · 仅作风格创作 · 非真实照片”。

## 2. 系统供应适配

生产实现使用 iOS 18.4+ `ImagePlayground` 框架：

1. 将原始照片归一为最长边不超过 2048 像素的不透明 `CGImage`。
2. 创建 Apple `ImageCreator`。
3. 只在 `.illustration` 可用时继续。
4. 输入一个图片概念和一个固定内部植物神话概念。
5. 限制只取一张结果，再由 `MythicGardenCardRenderer` 排成 1080 × 1440 不透明收藏卡。

内部概念不会显示给用户，也不会写入事件、数据库或个人数据导出。错误会映射为不支持、来源图片不适合、人物过小、语言不支持、取消、无结果或一般失败等固定恢复文案。

## 3. 能力、网络与费用边界

| 字段 | Apple 系统创作口径 |
| --- | --- |
| `provider` | `apple_image_playground` |
| `providerRequestCount` | `1` |
| `externalRequestCount` | 未向 App 暴露，保存为未知 |
| `networkTransport` | `system_managed` |
| `externalCost` | 未向 App 暴露，保存为 `not_exposed` |
| `quality` | `user_review_required` |

Adonis 没有为该能力配置第三方图片 API、API Key、账号或付费套餐，但这不等于可以宣称它完全离线、零网络或免费。系统处理与可能的网络传输由 Apple 管理；当前工程没有证据把未知值改写为 0。

## 4. 取消、超时和迟到结果

- 每次系统创作有独立 UUID 和任务句柄。
- 用户取消时先清除活动 ID、撤销 90 秒截止任务，再取消生成任务；任务随后返回的任何结果都不能打开作品页、写事件或保存作品。
- 90 秒到期时同样先清除活动 ID 并取消任务，页面显示恢复提示，原始照片、透明贴纸、收藏卡和未收藏结果均保持不变。
- 成功、失败、取消和超时会分别留下固定事件类型；详情只包含配方、来源、是否含 AI 像素、provider、请求/网络/费用/质量口径和固定错误码，不含照片、内部概念、文件路径或记录 ID。

## 5. 收藏、历史和数据控制

- 未收藏的永生花园只存在于内存，不会暗中建立草稿箱。
- 用户点击收藏时，作品 PNG 与 `mythic-garden-v1`、处理耗时和执行元数据一起关联原 OOTD。
- App 进程终止并重启后，花历中的原 OOTD 可重新打开同一作品、对照原始照片并分享。
- 删除原 OOTD 会级联删除作品模型和图片；“清空所有本地数据”覆盖作品、媒体和临时导出。
- `adonis-personal-data-v7` 的 `creativeWorks` 同时导出配方、图片来源、AI 像素标记、provider、provider 请求数、外部请求数、网络口径、费用口径和质量状态；系统未暴露的外部请求数会显式编码为 JSON `null`，不会与旧格式缺少字段或 0 次请求混淆。AI 作品在 `visualAssets` 中保持 `ai_generated`，不会与程序排版混淆。

## 6. Debug 夹具边界

模拟器专项通过 `#if DEBUG` 内的确定性夹具覆盖可用、不可用、成功、永不完成、取消和超时。夹具输出只是程序绘制的抽象色块，用于证明：

- 入口门控与一键流程；
- 生成中遮罩和取消入口；
- AI 来源说明、原图对照、收藏与系统分享；
- 跨进程历史回看；
- 超时与迟到结果隔离；
- 执行元数据持久化和 v7 TAR 导出。

夹具不能进入 Release，也不能用于评价 Apple 模型输出。任何产品截图如果来自该路径，都必须标为“Debug 夹具”，不得当作真实生成案例宣传。

## 7. 自动验证

专项命令：

```bash
make creative-regression
```

覆盖内容包括：

- 两种创作配方与用户文案不暴露技术术语；
- Apple 系统与本机排版的执行元数据；
- 花影海报与永生花园 1080 × 1440、不透明输出和来源页脚；
- SwiftData 执行元数据往返、作品关联和级联删除；
- 能力不可用隐藏入口、成功、取消和超时 UI；
- 收藏、系统分享、真实终止进程后重启与花历回看；
- v7 标准 TAR 中程序排版与 AI 生成作品的可区分字段；
- 全部本地数据清理。

本轮 `make creative-regression` 完成 18 个单元测试与 5 个真实模拟器 UI 流程，共 23 项通过、0 失败、0 跳过；`xcresulttool` 独立读取结果包后同样得到 23/23。结果包为 `.derivedData/Logs/Test/Test-Adonis-2026.08.30_11-51-28-+0800.xcresult`。

最大辅助字号 `accessibility-extra-extra-extra-large` 与增强对比度回归完成 1 个颜色契约单元测试和 5 个真实 UI 流程，共 6 项通过、0 失败、0 跳过；结果包为 `.derivedData/Logs/Test/Test-Adonis-2026.08.30_11-21-51-+0800.xcresult`。永生花园在该字号下使用菜单替代横向分段控件，仍可完成入口、生成、原图对照、来源说明、收藏、系统分享、进程终止重启和历史回看。脚本结束后重新读取模拟器设置，辅助字号已恢复为 `large`、增强对比度为 `disabled`；这不等同于真实 VoiceOver 验证。

完整工程门禁同样通过：`make check` 完成严格 Swift 格式检查与通用 iOS 静态分析；`make test` 完成 127 个单元测试与 28 个真实模拟器 UI 流程，共 155 项通过、0 失败、0 跳过，`xcresulttool` 独立汇总一致，结果包为 `.derivedData/Logs/Test/Test-Adonis-2026.08.30_11-55-11-+0800.xcresult`。

`Release`、`generic/platform=iOS`、`CODE_SIGNING_ALLOWED=NO` 构建成功，主 App 与分享扩展均为 arm64 Mach-O。系统创作测试替身及其启动参数位于 `#if DEBUG`；对两个 Release 二进制读取字符串时均未发现对应夹具标记。Debug 模拟器产物重新安装后，不带任何 UI 测试参数启动 `studio.adonis.localdemo`，`simctl launch` 返回进程 7225，随后从模拟器 `launchctl` 列表再次确认该进程仍存活；普通首页目检未见遮挡或截断。以上只证明编译隔离和普通模拟器启动，不是 App Store 签名安装或真实 iPhone 运行证据。

专项生成的 v7 TAR 还从 XCTest 结果包导出，并由 macOS `tar` 与 `jq` 独立读取：归档实际包含 `manifest.json`、7 个 `media/` PNG 和 1 个 `shared-inbox/` 文件；`visualAssets` 共 8 项，其中只有永生花园为 `ai_generated`，花影海报仍为 `programmatic_composition`。

## 9. 尚未证明

- 尚未在支持该能力的真实 iPhone 上调用并保存 Apple `ImageCreator` 的真实输出。
- 尚未用四张授权固定样本评价风格稳定性、脸部一致性、身体比例或衣物细节变化。
- 尚未验证真实处理时延、系统资源下载、语言/地区差异、弱网、飞行模式、系统级取消响应或费用表现。
- 尚未做真实 VoiceOver、真实系统分享目的地或实机前后台/锁屏中断验证。
- 尚未证明用户愿意收藏、分享或因此再次打开 Adonis。
- 尚未实现视觉试穿，也不能把永生花园描述成换装、尺码预测或真实摄影结果。

因此，这份记录可以作为“可用性门控 + 低心智系统创作 + 可追溯 AI 作品”的工程契约，但不能作为 Apple 真实输出质量、真机体验或产品价值已经成立的证据。
