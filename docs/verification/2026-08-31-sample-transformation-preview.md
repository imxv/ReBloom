# 2026-08-31 内置样片原图到贴纸预览验证

> 结论：创作首页的内置样片现在会在点击前并排展示原始照片与已经审核的透明贴纸，让第一次打开 Adonis 的用户直接看懂“一张照片会变成什么”。整张卡仍只有一次点击，不新增模式、参数或确认；样片明确标为“内置样片 / 原图处理”，不冒充当前设备实时生成的 AI 结果。

## 1. 用户体验契约

- 首页样片区标题直接说明“看看照片怎么变成贴纸”。
- 每张 A 级展示样片左侧显示授权原图，右侧显示对应的固定透明贴纸，中间只用一个方向箭头表达变化。
- 右侧预览和卡片说明分别显示“原图处理”与“原图 → 透明贴纸”；页面同时说明它是本机处理的内置样片。
- 整张样片卡仍是一个点击目标，点击后直接进入既有贴纸、收藏卡、收藏今天与分享流程，不增加新的选择页。
- VoiceOver 只聚焦整张卡，并朗读样片名称、原始照片变成透明贴纸、内置样片与原图处理来源；装饰图片和箭头不重复朗读。
- 普通字号卡宽为 214 点，辅助字号卡宽为 256 点；标题和说明保持内容驱动高度，横向列表仍可滚动。

## 2. 像素与来源边界

预览直接读取 `SampleCatalog.showcasePhotos` 中已经人工复核为 A 级的前三张样片，不生成或覆盖任何图片资产。左侧来自用户授权原图，右侧来自固定历史直抠贴纸；它们仍受 `regression-baseline.json`、哈希、字节级重生成和像素门禁约束。C 级 `sample-04` 继续从普通入口隐藏。

这条预览只解释内置体验样片，不代表当前设备已经运行 AI 图片生成，也不代表默认生产链路可以对用户原图直接抠图。用户自己的照片仍必须遵守“用户确认 AI 不透明底图 → 只把该底图交给第二段 AI 生成真实透明 PNG → 本机纯白边”的主链路。
