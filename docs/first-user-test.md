# ReBloom 首轮五人无讲解测试

> 对应 ADO-001、ADO-006、ADO-008、ADO-009。此文是执行模板，尚无参与者结果；不能据此勾选用户测试或 MVP 验证完成。

## 这轮只验证什么

一个会拍自拍或 OOTD、希望留下好看作品、又不愿学习 AI 工具的人，能否自己看懂入口、做出属于自己的贴纸、保存后再找到它。

先记录参与者最近一次实际拍摄、保存或分享穿搭照片的情境。年龄、性别和获客渠道不能替代真实行为；当前用户画像仍是假设。每人只记匿名编号 P01—P05，不把姓名、照片或社交账号写入公共验证文档。

## 开始前选择真实可用的测试范围

- **样片流程测试**：不需要实时生成服务，输入是已明确标注的内置 AI 样片。只测理解、操作与保存位置；不能评价用户自己的生成质量或真实时延。
- **用户照片完整测试**：必须先确认目标 iPhone 能打开系统 Image Playground、透明处理服务可用。用户主动选图并在系统页确认底图后，只有该 AI 底图进入透明服务；不向代理上传用户原图。支持设备与真实服务缺一项时，记录阻塞，不拿样片代替成功。

复用既有授权与隐私说明，不在体验前增加风格、身体信息或衣橱问卷。研究记录、截图或留存参与者图片需要单独获得其同意；未同意的图片不进入回归集。

## 主持人只给任务，不教点哪里

1. “先看看这个应用。你觉得它可以帮你做什么？”记录原话，不介绍花历、衣橱或 AI 流程。
2. “试着做一张你愿意留下的作品。”只使用已确定的测试范围；让参与者自行选择照片或明确点击样片。
3. 结果出现后先不提示收藏：“接下来你想做什么？”观察是否主动查看原图、保存、分享或离开。
4. “请把这张作品留在应用里，以后还能找到。”记录第一次实际点按的按钮及其预期位置。
5. “再把透明贴纸存到手机相册。”实际打开照片 App 检查文件；权限拒绝、设置恢复或失败也照实记录。
6. 结束 App 进程并重新打开：“请找到刚才留下的作品。”不提示花历入口。
7. 最后问：“什么时候你会想再用一次？”记录具体触发；“挺好看”“以后可能用”不等同于回访意愿成立。

卡住时先问“你现在想做什么、期待点了会怎样”，再记录是否需要主持人帮助。需要帮助后可以继续，但该步骤不再计为独立完成。参与者可以随时停止，不为完成测试强迫生成、上传、相册授权或对外分享。

## 如何决定下一轮改什么

优先处理让任务中断、结果丢失、保存位置误解或人物/衣服明显改变的问题。多个参与者卡在同一步时，先改该步骤再复测；不先增加新风格或新入口。

五人只用于发现问题和收敛场景，不足以证明总体成功率、留存率或市场规模。汇总时分开呈现样片与用户照片，保留全部失败。只有真实观察完成后，才按证据更新 TODO 的 ADO-001 / ADO-008，并决定 ADO-009 的首版保留范围。
